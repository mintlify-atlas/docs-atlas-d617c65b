## What's This Project?

Maymoun's Portfolio is a full-featured Next.js 13 application that combines a personal portfolio with a blog platform. Built with modern web technologies, it provides a fast, responsive, and SEO-friendly platform for sharing technical content and professional information.

The project leverages the Next.js App Router, TypeScript for type safety, Tailwind CSS for styling, and Contentlayer for managing MDX blog posts with excellent developer experience.

## Technology Stack

This project is built with a modern tech stack focused on developer experience and performance:

- **Framework**: Next.js 13 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Content**: Contentlayer for MDX processing
- **Deployment**: Optimized for Vercel deployment
- **Search**: kbar for command palette search
- **Analytics**: Umami analytics support
- **Comments**: Giscus (GitHub Discussions)
- **Newsletter**: Buttondown integration
