## Overview

Maymoun's Portfolio uses Tailwind CSS for styling, providing a highly customizable design system. The main configuration is in `tailwind.config.js`, with additional custom CSS in the `css/` directory.

## Tailwind CSS Configuration

The Tailwind configuration file controls the entire design system of your portfolio.

### Configuration File Structure

```javascript tailwind.config.js
const { fontFamily } = require('tailwindcss/defaultTheme')
const colors = require('tailwindcss/colors')

module.exports = {
  content: [
    './node_modules/pliny/**/*.js',
    './app/**/*.{js,ts,jsx,tsx}',
    './pages/**/*.{js,ts,tsx}',
    './components/**/*.{js,ts,tsx}',
    './layouts/**/*.{js,ts,tsx}',
    './data/**/*.mdx',
  ],
  darkMode: 'class',
  theme: {
    extend: {
      // Custom configurations
    },
  },
  plugins: [require('@tailwindcss/forms'), require('@tailwindcss/typography')],
}
```

<Note>
  The `content` array tells Tailwind where to look for class names to include in the final CSS bundle. Make sure to include all paths where you use Tailwind classes.
</Note>

## Typography Configuration

### Font Families

The portfolio uses Space Grotesk as the default sans-serif font:

```javascript tailwind.config.js
module.exports = {
  theme: {
    extend: {
      fontFamily: {
        sans: ['var(--font-space-grotesk)', ...fontFamily.sans],
      },
    },
  },
}
```

<Steps>
  <Step title="Change Font Family">
    To use a different font, update the configuration:

    ```javascript tailwind.config.js
    fontFamily: {
      sans: ['Inter', 'system-ui', 'sans-serif'],
      // or
      sans: ['Poppins', 'system-ui', 'sans-serif'],
      // or
      sans: ['Roboto', 'system-ui', 'sans-serif'],
    }
    ```
  </Step>

  <Step title="Add Font Source">
    If using Google Fonts, add to your layout or `_app.js`:

    ```javascript
    import { Inter } from 'next/font/google'

    const inter = Inter({ subsets: ['latin'] })
    ```
  </Step>
</Steps>

### Typography Plugin

The `@tailwindcss/typography` plugin provides beautiful typography defaults for MDX content:

```javascript tailwind.config.js
module.exports = {
  theme: {
    extend: {
      typography: ({ theme }) => ({
        DEFAULT: {
          css: {
            a: {
              color: theme('colors.primary.500'),
              '&:hover': {
                color: `${theme('colors.primary.600')}`,
              },
              code: { color: theme('colors.primary.400') },
            },
            'h1,h2': {
              fontWeight: '700',
              letterSpacing: theme('letterSpacing.tight'),
            },
            h3: {
              fontWeight: '600',
            },
            code: {
              color: theme('colors.indigo.500'),
            },
          },
        },
        invert: {
          css: {
            a: {
              color: theme('colors.primary.500'),
              '&:hover': {
                color: `${theme('colors.primary.400')}`,
              },
              code: { color: theme('colors.primary.400') },
            },
            'h1,h2,h3,h4,h5,h6': {
              color: theme('colors.gray.100'),
            },
          },
        },
      }),
    },
  },
  plugins: [require('@tailwindcss/typography')],
}
```

<Note>
  The `invert` variant provides dark mode-optimized typography styles. It's automatically applied when dark mode is active.
</Note>

## Dark Mode Configuration

The portfolio uses class-based dark mode:

```javascript tailwind.config.js
module.exports = {
  darkMode: 'class',
  // ...
}
```

<Steps>
  <Step title="Understanding Dark Mode">
    When `darkMode: 'class'` is set, dark mode styles apply when a parent element has the `dark` class:

    ```html
    <html class="dark">
      <!-- Dark mode is active -->
    </html>
    ```
  </Step>

  <Step title="Using Dark Mode Variants">
    Apply dark mode styles using the `dark:` variant:

    ```html
    <div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100">
      Content adapts to light and dark modes
    </div>
    ```
  </Step>

  <Step title="Typography Dark Mode">
    The typography plugin automatically handles dark mode with the `prose-invert` class:

    ```html
    <article class="prose dark:prose-invert">
      <!-- Typography adapts to dark mode -->
    </article>
    ```
  </Step>
</Steps>

## Custom Styling Examples

### Creating Custom Components

Add custom component classes to `css/tailwind.css`:

```css css/tailwind.css
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer components {
  .btn-primary {
    @apply rounded-lg bg-primary-500 px-4 py-2 font-semibold text-white transition-colors hover:bg-primary-600 dark:bg-primary-600 dark:hover:bg-primary-700;
  }

  .card {
    @apply rounded-lg border border-gray-200 bg-white p-6 shadow-sm dark:border-gray-700 dark:bg-gray-800;
  }

  .input-field {
    @apply w-full rounded-md border border-gray-300 px-3 py-2 focus:border-primary-500 focus:outline-none focus:ring-1 focus:ring-primary-500 dark:border-gray-600 dark:bg-gray-700;
  }
}
```

### Custom Utilities

Add custom utility classes:

```css css/tailwind.css
@layer utilities {
  .text-gradient {
    @apply bg-gradient-to-r from-primary-400 to-primary-600 bg-clip-text text-transparent;
  }

  .scrollbar-hide {
    -ms-overflow-style: none;
    scrollbar-width: none;
  }

  .scrollbar-hide::-webkit-scrollbar {
    display: none;
  }
}
```

## Production Optimization

Tailwind automatically removes unused CSS in production builds. The `content` configuration ensures only classes you actually use are included:

```javascript tailwind.config.js
module.exports = {
  content: [
    './node_modules/pliny/**/*.js',
    './app/**/*.{js,ts,jsx,tsx}',
    './pages/**/*.{js,ts,tsx}',
    './components/**/*.{js,ts,tsx}',
    './layouts/**/*.{js,ts,tsx}',
    './data/**/*.mdx', // Important for MDX content!
  ],
}
```

<Warning>
  Make sure to include all paths where you use Tailwind classes. If you add new directories, update the `content` array.
</Warning>
