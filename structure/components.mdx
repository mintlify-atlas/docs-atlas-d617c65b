## Component Architecture

The portfolio uses a collection of reusable React components located in the `components/` directory. All components are built with TypeScript and styled with Tailwind CSS.

## Core Components

### Header Component

The main navigation header with logo, navigation links, and theme switcher.

**Location**: `components/Header.tsx`

```tsx
const Header = () => {
  return (
    <header className="flex items-center justify-between py-10">
      <div>
        <Link href="/" aria-label={siteMetadata.headerTitle}>
          <div className="flex items-center justify-between">
            <div className="hidden h-6 text-2xl font-semibold sm:block">
              <span>ⴰⵎⴰⵍⵓ</span>
            </div>
            <div className="hidden h-6 text-2xl font-semibold sm:block">

            </div>

```

**Features**:
- Responsive design with mobile navigation
- Dynamic navigation from `data/headerNavLinks.ts`
- Integrated theme switcher
- Tifinagh logo display

### Card Component

A flexible card component for displaying projects or featured content.

**Location**: `components/Card.tsx`

```tsx
interface CardProps {
  title: string
  description: string
  imgSrc?: string
  href?: string
}

const Card = ({ title, description, imgSrc, href }: CardProps) => (
  <div className="md max-w-[544px] p-4 md:w-1/2">
    <div className="overflow-hidden rounded-md border-2 border-gray-200 dark:border-gray-700">
      {imgSrc && (
        <Link href={href} aria-label={`Link to ${title}`}>
          <Image
            alt={title}
            src={imgSrc}
            className="object-cover object-center md:h-36 lg:h-48"
            width={544}
            height={306}
          />
        </Link>
      )}
      <div className="p-6">
        <h2 className="mb-3 text-2xl font-bold">
          {href ? <Link href={href}>{title}</Link> : title}
        </h2>
        <p className="prose mb-3 text-gray-500 dark:text-gray-400">
          {description}
        </p>
        {href && (
          <Link href={href} className="text-primary-500 hover:text-primary-600">
            Learn more &rarr;
          </Link>
        )}
      </div>
    </div>
  </div>
)
```

**Props**:
- `title` (string, required) - Card title
- `description` (string, required) - Card description
- `imgSrc` (string, optional) - Image source URL
- `href` (string, optional) - Link destination

**Usage Example**:
```tsx
<Card
  title="My Project"
  description="A cool project I built"
  imgSrc="/static/images/project.jpg"
  href="/projects/my-project"
/>
```

### Link Component

Custom link wrapper that handles internal, external, and anchor links.

**Location**: `components/Link.tsx`

```tsx
const CustomLink = ({ href, ...rest }: LinkProps) => {
  const isInternalLink = href && href.startsWith('/')
  const isAnchorLink = href && href.startsWith('#')

  if (isInternalLink) {
    return <Link href={href} {...rest} />
  }

  if (isAnchorLink) {
    return <a href={href} {...rest} />
  }

  return <a target="_blank" rel="noopener noreferrer" href={href} {...rest} />
}
```

**Features**:
- Automatic Next.js Link for internal routes
- External links open in new tab with security attributes
- Anchor links for same-page navigation

### Image Component

Wrapper around Next.js Image for optimized images.

**Location**: `components/Image.tsx`

```tsx
const Image = ({ ...rest }: ImageProps) => <NextImage {...rest} />
```

Provides all Next.js Image optimization features:
- Automatic WebP/AVIF conversion
- Lazy loading
- Responsive images
- Blur placeholder support

### Tag Component

Clickable tag component for blog post categorization.

**Location**: `components/Tag.tsx`

```tsx
interface Props {
  text: string
}

const Tag = ({ text }: Props) => {
  return (
    <Link
      href={`/tags/${slug(text)}`}
      className="mr-3 text-sm font-medium uppercase text-primary-500"
    >
      {text.split(' ').join('-')}
    </Link>
  )
}
```

**Features**:
- Automatic slug generation with `github-slugger`
- Links to tag filter pages
- Consistent styling with theme colors

Main layout wrapper that provides the overall page structure with header, footer, and content area.

**Location**: `components/LayoutWrapper.tsx`

## Adding Custom Components

<Steps>
  <Step title="Create Component File">
    Create a new `.tsx` file in `components/` directory
    ```tsx
    // components/MyComponent.tsx
    interface MyComponentProps {
      title: string
    }
    
    const MyComponent = ({ title }: MyComponentProps) => {
      return <div>{title}</div>
    }
    
    export default MyComponent
    ```
  </Step>
  
  <Step title="Import and Use">
    Import the component where needed
    ```tsx
    import MyComponent from '@/components/MyComponent'
    
    <MyComponent title="Hello" />
    ```
  </Step>
  
  <Step title="Add to MDX (Optional)">
    To use in MDX content, add to `MDXComponents.tsx`
    ```tsx
    export const components: MDXComponents = {
      // ... existing components
      MyComponent,
    }
    ```
  </Step>
</Steps>

<Note>
All components support dark mode through Tailwind's `dark:` variants. Make sure to include appropriate dark mode styles when creating new components.
</Note>
