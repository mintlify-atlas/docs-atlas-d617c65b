### Document Types

Two document types are defined: `Blog` and `Authors`.

<Tabs>
  <Tab title="Blog Document">
    ```typescript
    export const Blog = defineDocumentType(() => ({
      name: 'Blog',
      filePathPattern: 'blog/**/*.mdx',
      contentType: 'mdx',
      fields: {
        title: { type: 'string', required: true },
        date: { type: 'date', required: true },
        tags: { type: 'list', of: { type: 'string' }, default: [] },
        lastmod: { type: 'date' },
        draft: { type: 'boolean' },
        summary: { type: 'string' },
        images: { type: 'json' },
        authors: { type: 'list', of: { type: 'string' } },
        layout: { type: 'string' },
        bibliography: { type: 'string' },
        canonicalUrl: { type: 'string' },
      },
      computedFields: {
        readingTime: { 
          type: 'json', 
          resolve: (doc) => readingTime(doc.body.raw) 
        },
        slug: {
          type: 'string',
          resolve: (doc) => doc._raw.flattenedPath.replace(/^.+?(\/)/, ''),
        },
        path: {
          type: 'string',
          resolve: (doc) => doc._raw.flattenedPath,
        },
        filePath: {
          type: 'string',
          resolve: (doc) => doc._raw.sourceFilePath,
        },
        toc: { 
          type: 'string', 
          resolve: (doc) => extractTocHeadings(doc.body.raw) 
        },
        structuredData: {
          type: 'json',
          resolve: (doc) => ({
            '@context': 'https://schema.org',
            '@type': 'BlogPosting',
            headline: doc.title,
            datePublished: doc.date,
            dateModified: doc.lastmod || doc.date,
            description: doc.summary,
            image: doc.images ? doc.images[0] : siteMetadata.socialBanner,
            url: `${siteMetadata.siteUrl}/${doc._raw.flattenedPath}`,
          }),
        },
      },
    }))
    ```
    
    **Fields**:
    - `title` (required) - Post title
    - `date` (required) - Publication date
    - `tags` - Array of tag strings
    - `summary` - Post excerpt
    - `authors` - Author references
    - `layout` - Layout component name
    - `draft` - Hide from production
    - `images` - Featured images
    
    **Computed Fields**:
    - `readingTime` - Auto-calculated reading time
    - `slug` - URL-friendly slug
    - `toc` - Table of contents
    - `structuredData` - SEO schema markup
  </Tab>

### MDX Plugins

Contentlayer is configured with powerful MDX processing plugins:

#### Remark Plugins (Markdown Processing)

```typescript
remarkPlugins: [
  remarkExtractFrontmatter,  // Extract YAML frontmatter
  remarkGfm,                 // GitHub Flavored Markdown
  remarkCodeTitles,          // Code block titles
  remarkMath,                // Math equations
  remarkImgToJsx,            // Convert images to JSX
]
```

<Accordion title="Remark Plugin Details">
- **remarkExtractFrontmatter**: Parses YAML frontmatter into typed data
- **remarkGfm**: Adds tables, task lists, strikethrough, autolinks
- **remarkCodeTitles**: Enables code block titles like ` ```js:filename.js`
- **remarkMath**: LaTeX math support with KaTeX
- **remarkImgToJsx**: Transforms markdown images to Next.js Image components
</Accordion>

#### Rehype Plugins (HTML Processing)

```typescript
rehypePlugins: [
  rehypeSlug,                               // Add IDs to headings
  rehypeAutolinkHeadings,                   // Add anchor links to headings
  rehypeKatex,                              // Render math equations
  [rehypeCitation, { path: path.join(root, 'data') }],
  [rehypePrismPlus, { 
    defaultLanguage: 'js', 
    ignoreMissing: true 
  }],
  rehypePresetMinify,                       // Minify output HTML
]
```

<Accordion title="Rehype Plugin Details">
- **rehypeSlug**: Generates heading IDs for anchor links
- **rehypeAutolinkHeadings**: Clickable heading anchors
- **rehypeKatex**: Renders LaTeX math with KaTeX
- **rehypeCitation**: Academic citation support
- **rehypePrismPlus**: Syntax highlighting with line numbers and highlighting
- **rehypePresetMinify**: Minifies HTML output
</Accordion>

### Build Hooks

```typescript
export default makeSource({
  contentDirPath: 'data',
  documentTypes: [Blog, Authors],
  mdx: { /* ... */ },
  onSuccess: async (importData) => {
    const { allBlogs } = await importData()
    createTagCount(allBlogs)      // Generate tag-data.json
    createSearchIndex(allBlogs)   // Generate search.json
  },
})
```

**Post-processing**:
1. **Tag Count Generation**: Creates `app/tag-data.json` with tag statistics
2. **Search Index**: Generates `public/search.json` for kbar search

## Using Content in Components

### Import Generated Types

```typescript
import { allBlogs, allAuthors } from 'contentlayer/generated'
import type { Blog, Authors } from 'contentlayer/generated'
```

### Query Blog Posts

```tsx
// Get all published posts
const posts = allBlogs
  .filter((post) => !post.draft)
  .sort((a, b) => new Date(b.date).getTime() - new Date(a.date).getTime())

// Get single post by slug
const post = allBlogs.find((p) => p.slug === 'meet-kafka')

// Get posts by tag
const taggedPosts = allBlogs.filter((post) => 
  post.tags?.includes('kafka')
)
```

### Render MDX Content

```tsx
import { useMDXComponent } from 'next-contentlayer/hooks'
import { components } from '@/components/MDXComponents'

export default function BlogPost({ post }: { post: Blog }) {
  const MDXContent = useMDXComponent(post.body.code)
  
  return (
    <article>
      <h1>{post.title}</h1>
      <time>{post.date}</time>
      <MDXContent components={components} />
    </article>
  )
}
```

## Adding New Content

<Steps>
  <Step title="Create MDX File">
    Create a new `.mdx` file in `data/blog/`:
    
    ```bash
    touch data/blog/my-new-post.mdx
    ```
  </Step>
  
  <Step title="Add Frontmatter">
    Add required frontmatter:
    
    ```yaml
    ---
    title: 'My New Post'
    date: '2024-03-08'
    tags: ['nextjs', 'react']
    summary: 'A brief description'
    authors: ['default']
    ---
    ```
  </Step>
  
  <Step title="Write Content">
    Write your content in MDX:
    
    ```mdx
    # Introduction
    
    This is my new blog post...
    
    <Image src="/static/images/example.jpg" alt="Example" />
    ```
  </Step>
  
  <Step title="View Changes">
    Contentlayer will automatically detect changes in development mode:
    
    ```bash
    yarn dev
    ```
    
    Navigate to `/blog/my-new-post`
  </Step>
</Steps>

<Note>
**Draft Posts**: Set `draft: true` in frontmatter to hide posts from production builds while keeping them visible in development.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Contentlayer not detecting changes">
    1. Restart the dev server
    2. Delete `.contentlayer` folder and restart
    3. Check for syntax errors in frontmatter
  </Accordion>
  
  <Accordion title="Images not displaying">
    1. Ensure images are in `public/static/images/`
    2. Use absolute paths: `/static/images/photo.jpg`
    3. Check image domains in `next.config.js`
  </Accordion>
  
  <Accordion title="Type errors with generated types">
    1. Run `yarn dev` to regenerate types
    2. Restart TypeScript server in your editor
    3. Check for typos in field names
  </Accordion>
</AccordionGroup>
