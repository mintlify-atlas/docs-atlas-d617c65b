## Architecture Overview

Maymoun's Portfolio is built with **Next.js 13** using the App Router architecture, featuring a modern tech blog with MDX content management through Contentlayer.

## Next.js App Router Setup

The application uses Next.js 13's App Router with the following structure:

### Root Layout

The main layout (`app/layout.tsx`) wraps all pages:

```tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang={siteMetadata.language} suppressHydrationWarning>
      <body>
        <ThemeProviders>
          <Analytics analyticsConfig={siteMetadata.analytics} />
          <SectionContainer>
            <div className="flex h-screen flex-col justify-between">
              <SearchProvider searchConfig={siteMetadata.search}>
                <Header />
                <main className="mb-auto">{children}</main>
              </SearchProvider>
              <Footer />
            </div>
          </SectionContainer>
        </ThemeProviders>
      </body>
    </html>
  )
}
```

### Route Organization

<Tabs>
  <Tab title="Blog Routes">
    - `/blog` - Blog listing page with tags sidebar
    - `/blog/page/[page]` - Paginated blog posts
    - `/blog/[...slug]` - Individual blog post pages
    
    Dynamic route example:
    ```tsx
    // app/blog/[...slug]/page.tsx
    export async function generateStaticParams() {
      return allBlogs.map((post) => ({
        slug: post.slug.split('/')
      }))
    }
    ```
  </Tab>
  
  <Tab title="Tag Routes">
    - `/tags` - All tags overview
    - `/tags/[tag]` - Posts filtered by tag
    
    Automatic tag generation from blog posts using `github-slugger`.
  </Tab>
  
  <Tab title="Static Routes">
    - `/` - Home page
    - `/about` - About page with author layout
    - `/contact` - Contact page
    - `/books` - Books page
  </Tab>
  
  <Tab title="API Routes">
    - `/api/newsletter` - Newsletter subscription endpoint
    
    Server-side API handling with Next.js Route Handlers.
  </Tab>
</Tabs>

## Key Configuration Files

### next.config.js

Configures Next.js with Contentlayer integration, security headers, and image domains:

```javascript
const { withContentlayer } = require('next-contentlayer')

module.exports = () => {
  const plugins = [withContentlayer, withBundleAnalyzer]
  return plugins.reduce((acc, next) => next(acc), {
    reactStrictMode: true,
    pageExtensions: ['ts', 'tsx', 'js', 'jsx', 'md', 'mdx'],
    images: {
      domains: ['picsum.photos'],
    },
    // ... security headers and webpack config
  })
}
```

### tsconfig.json

```json
{
  "compilerOptions": {

    "paths": {

      "@/layouts/*": ["layouts/*"]
    }
  }
}
```

## Build Process

<Steps>
  <Step title="Content Processing">
    Contentlayer processes MDX files from `data/blog/` and `data/authors/` into type-safe data
  </Step>
  
  <Step title="Tag Generation">
    Build script generates `tag-data.json` with tag counts for filtering
  </Step>
  
  <Step title="Search Index">
    Creates `search.json` for client-side search with kbar
  </Step>
  
  <Step title="Static Generation">
    Next.js generates static pages for all blog posts and routes
  </Step>
</Steps>

<Note>
**Development Command**: `yarn dev` or `npm run dev`

**Build Command**: `yarn build` or `npm run build`

The build process includes Contentlayer compilation and post-build scripts.
</Note>

## Performance Features

- **Static Site Generation (SSG)** - Pre-rendered pages at build time
- **Image Optimization** - Next.js Image component with automatic optimization
- **Code Splitting** - Automatic route-based code splitting
- **CSS Optimization** - Tailwind CSS with PurgeCSS for minimal bundle size
- **Bundle Analysis** - Optional bundle analyzer with `ANALYZE=true`
