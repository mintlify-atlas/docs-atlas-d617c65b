Get started with Maymoun's Portfolio by following this step-by-step guide. You'll have a fully functional Next.js blog and portfolio running locally in just a few minutes.

## Prerequisites

Before you begin, ensure you have the following installed:
- Node.js 16.x or higher
- Yarn 3.6.1 or higher (recommended) or npm/pnpm

## Installation

<Steps>
  <Step title="Clone the repository">
    First, clone the repository to your local machine:

    ```bash
    git clone https://github.com/Amalou99/melfahim-portfolio.git
    cd melfahim-portfolio
    ```
  </Step>

  <Step title="Install dependencies">
    Install all required packages using your preferred package manager:

    <CodeGroup>
      ```bash yarn
      yarn
      ```

      ```bash npm
      npm install
      ```

      ```bash pnpm
      pnpm install
      ```
    </CodeGroup>

    <Note>
      This project uses Yarn 3.6.1 as specified in `package.json`. If you're using Yarn, the correct version will be automatically used.
    </Note>
  </Step>

  <Step title="Configure environment variables">
    Copy the example environment file and configure it for your needs:

    ```bash
    cp .env.example .env
    ```

    The `.env` file contains optional configurations for:

    ```bash .env
    # Comment system (Giscus, Utterances, or Disqus)
    NEXT_PUBLIC_GISCUS_REPO=
    NEXT_PUBLIC_GISCUS_REPOSITORY_ID=
    NEXT_PUBLIC_GISCUS_CATEGORY=
    NEXT_PUBLIC_GISCUS_CATEGORY_ID=
    NEXT_PUBLIC_UTTERANCES_REPO=
    NEXT_PUBLIC_DISQUS_SHORTNAME=

    # Newsletter providers
    MAILCHIMP_API_KEY=
    MAILCHIMP_API_SERVER=
    MAILCHIMP_AUDIENCE_ID=
    BUTTONDOWN_API_KEY=
    CONVERTKIT_API_KEY=
    CONVERTKIT_FORM_ID=
    KLAVIYO_API_KEY=
    KLAVIYO_LIST_ID=
    REVUE_API_KEY=
    EMAILOCTOPUS_API_KEY=
    EMAILOCTOPUS_LIST_ID=

    # Analytics
    NEXT_UMAMI_ID=
    ```

    <Warning>
      All environment variables are optional. The site will run without them, but features like comments and newsletter subscriptions won't work until configured.
    </Warning>
  </Step>

  <Step title="Start the development server">
    Run the development server:

    <CodeGroup>
      ```bash yarn
      yarn dev
      ```

      ```bash npm
      npm run dev
      ```

      ```bash pnpm
      pnpm dev
      ```
    </CodeGroup>

    The server will start on [http://localhost:3000](http://localhost:3000). Open this URL in your browser to see your portfolio.

    <Note>
      The `dev` script uses `cross-env` to set the `INIT_CWD` environment variable, ensuring proper path resolution across different operating systems.
    </Note>
  </Step>
</Steps>

## Available Scripts

The project includes several useful scripts defined in `package.json`:

<AccordionGroup>
  <Accordion title="Development Scripts">
    ```json package.json
    {
      "scripts": {
        "start": "next dev",
        "dev": "cross-env INIT_CWD=$PWD next dev"
      }
    }
    ```

    - `yarn dev` - Starts the Next.js development server with hot reloading
    - `yarn start` - Alternative command to start the development server
  </Accordion>

  <Accordion title="Production Scripts">
    ```json package.json
    {
      "scripts": {
        "build": "CI=false cross-env INIT_CWD=$PWD next build && cross-env NODE_OPTIONS='--experimental-json-modules' node ./scripts/postbuild.mjs",
        "serve": "next start"
      }
    }
    ```

    - `yarn build` - Creates an optimized production build
    - `yarn serve` - Starts the production server (run after `yarn build`)
  </Accordion>

  <Accordion title="Utility Scripts">
    ```json package.json
    {
      "scripts": {
        "analyze": "cross-env ANALYZE=true next build",
        "lint": "next lint --fix --dir pages --dir app --dir components --dir lib --dir layouts --dir scripts"
      }
    }
    ```

    - `yarn analyze` - Analyzes the bundle size using @next/bundle-analyzer
    - `yarn lint` - Runs ESLint and automatically fixes issues
  </Accordion>
</AccordionGroup>

## Building for Production

To create a production-ready build:

<Steps>
  <Step title="Create the production build">
    <CodeGroup>
      ```bash yarn
      yarn build
      ```

      ```bash npm
      npm run build
      ```

      ```bash pnpm
      pnpm build
      ```
    </CodeGroup>

    This command:
    1. Disables CI mode warnings (`CI=false`)
    2. Builds the Next.js application
    3. Runs the postbuild script to generate additional assets
  </Step>

  <Step title="Start the production server">
    <CodeGroup>
      ```bash yarn
      yarn serve
      ```

      ```bash npm
      npm run serve
      ```

      ```bash pnpm
      pnpm serve
      ```
    </CodeGroup>

    Your production site will be available at [http://localhost:3000](http://localhost:3000).
  </Step>
</Steps>

## Project Structure

After installation, your project will have the following structure:

```
melfahim-portfolio/
├── app/              # Next.js 13+ app directory
├── components/       # React components
├── data/             # Site metadata and configuration
│   └── siteMetadata.js
├── layouts/          # Page layouts
├── lib/              # Utility functions and libraries
├── pages/            # Legacy pages (if any)
├── public/           # Static assets
├── scripts/          # Build and utility scripts
├── .env.example      # Environment variables template
├── contentlayer.config.ts  # Contentlayer configuration
├── next.config.js    # Next.js configuration
├── package.json      # Dependencies and scripts
└── tailwind.config.js # Tailwind CSS configuration
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Port 3000 already in use">
    If port 3000 is already occupied, you can specify a different port:

    ```bash
    yarn dev -p 3001
    ```
  </Accordion>

  <Accordion title="Module not found errors">
    Clear your node_modules and reinstall:

    ```bash
    rm -rf node_modules yarn.lock
    yarn install
    ```
  </Accordion>

  <Accordion title="Build fails with memory errors">
    Increase Node.js memory limit:

    ```bash
    NODE_OPTIONS="--max-old-space-size=4096" yarn build
    ```
  </Accordion>
</AccordionGroup>
